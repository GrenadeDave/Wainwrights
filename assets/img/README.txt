DROP THE PHOTOS IN THIS FOLDER
==============================

Save photos here using these exact filenames (all lowercase, .jpg).
The website picks them up automatically — nothing else to change.

Any photo that is missing shows a tidy "photo coming soon" placeholder
instead of breaking the layout, so you can add them a few at a time.

TIPS
----
- BEFORE AND AFTER pairs are by far the most persuasive photos on a site
  like this. If you have any at all, use them.
- Phone photos are perfectly fine. Shoot in landscape unless the filename
  above says "tall".
- Files over about 2MB will slow the site down. Worth shrinking.
- PNG works too — just rename the file to .jpg, or ask and the references
  can be switched over.
- Shoot the "after" from the same spot as the "before". It is the
  difference between a nice photo and a convincing one.
